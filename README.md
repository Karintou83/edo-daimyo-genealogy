# 江戸藩主家系図

江戸時代の藩主を血縁関係(実父子関係)でつないだインタラクティブな家系図サイト。

## 方針

- ノードに持たせる情報: 藩名+代数(例: 加賀藩5代目)、氏名、Wikipedia記事へのリンク
- エッジ: 実の親子関係のみ。養子として藩主になった場合は実父とつなぐ(養父とはつながない)
- データ取得元: 日本語版Wikipediaの藩主継承テンプレート(例: {{佐賀藩主}})とリンク先記事のInfobox
- 表示: D3.jsによるインタラクティブな家系図(ズーム・パン、ノードクリックで詳細表示)

## 進め方

1. プロトタイプ対象: 米沢藩(上杉家、養子継承あり)・加賀藩(前田家、直系継承が多い)
2. `scripts/` にデータ取得・変換スクリプトを置く
   - フェーズ1: Wikipediaから藩主一覧とInfoboxの「父」情報を取得 → `data/daimyo_raw.json`
   - フェーズ2: raw データから nodes/edges を組み立て → `data/tree.json`
3. `tree.json` を読み込んで表示する静的サイト(index.html)を作る
4. 対象藩を増やす場合は、フェーズ1の対象藩リストを増やすだけで拡張できるようにする

## ディレクトリ構成

```
edo-daimyo-genealogy/
├── data/       取得・変換したデータ(JSON)
├── scripts/    データ取得・変換用スクリプト
└── index.html  家系図表示サイト(後で作成)
```
